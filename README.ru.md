# UAsset Importer

Импортируйте внешние пакеты Unreal Engine в формате .uasset в свой проект и выбирайте, какие зависимости переносить вместе с ними.

Откройте один или несколько ассетов через Content Browser. Проверьте пути пакетов и ссылки, выберите папки для ассетов и зависимостей, затем запустите импорт. Если сохранить структуру исходной папки Content, плагину будет проще найти связанные пакеты.

## Возможности

- До копирования проверьте дерево зависимостей. В нём видно, какие пакеты найдены в источнике, какие уже есть в проекте и какие ссылки остались неразрешёнными.
- Сохраните исходные пути пакетов или разложите ассеты и зависимости по выбранным папкам.
- Управляйте заменой существующих ассетов и резервным копированием на время импорта.

## Использование плагина

### Включение плагина

Откройте **Edit → Plugins**, найдите **UAsset Importer**, включите плагин и перезапустите редактор, если он предложит это сделать.

### Выбор ассетов и зависимостей

1. Откройте целевую папку в **Content Browser**. Перетащите внешние файлы `.uasset` в область ассетов или нажмите **Import** и выберите файлы.
2. В списке **Assets to Import** отметьте нужные ассеты. Кнопка **Load selected previews** загружает выбранные пакеты и создаёт миниатюры для поддерживаемых типов.
3. Раскройте **Dependencies**. Проверьте отсутствующие ссылки и отметьте пакеты, которые нужно скопировать. Если пропустить используемую зависимость, для работы ассета потребуется совместимый пакет по ожидаемому пути.

### Размещение пакетов

В поле **Destination** выберите, куда импортировать основные ассеты: в текущую папку Content Browser, корень Content, произвольную папку или по исходным путям. Настройка **Dependency placement** позволяет сохранить исходные пути зависимостей, воспроизвести их структуру внутри папки Dependencies, собрать их в одной папке Dependencies или положить рядом с основными ассетами. При сохранении исходных путей основных ассетов зависимости тоже сохраняют свои пути.

### Импорт и проверка результата

По умолчанию отсутствие обязательной зависимости останавливает импорт. Отсутствующие мягкие ссылки могут выводиться как предупреждения. Параметр **Overwrite existing assets** выключен, а **Roll back copied files if import fails** включён. Разрешайте перезапись, когда действительно хотите заменить существующие пакеты.

Нажмите **Import**. По умолчанию Content Browser выделяет импортированные ассеты. Загрузка выбранных ассетов после импорта включается отдельно. Проблемы выводятся в канале **UAsset Importer** окна Message Log, сводка — в Output Log. Если восстановление не завершилось, сохраните каталог резервных копий, указанный в сообщении.

## Ограничения

- Для импорта выбирайте внешние файлы `.uasset`. Карты (`.umap`) этим способом не импортируются.
- Храните сопутствующие файлы пакета рядом с ассетом и по возможности сохраняйте структуру исходной папки Content. Восстановить отсутствующие исходные данные плагин не может.
- Редактор должен уметь читать пакеты и находить используемые в них классы. Импорт приготовленных для игры (cooked), повреждённых или несовместимых пакетов может завершиться ошибкой. Если ассеты используют классы других плагинов, установите эти плагины перед открытием ассетов.

## Сборка из исходников

### Сборка в проекте

Закройте редактор. Из корневой папки C++-проекта выполните:

```shell
git clone https://github.com/DontFWithTheJ/UE-UAsset-Importer.git Plugins/UAssetImporter
```

Проверьте наличие `Plugins/UAssetImporter/UAssetImporter.uplugin`. При необходимости обновите файлы проекта для вашей IDE. Соберите цель редактора проекта в конфигурации **Development Editor** для вашей платформы, откройте проект и включите плагин.

### Упаковка через Unreal Automation Tool

В Windows выполните команду в командной строке, подставив свои пути. Для результата выберите пустую папку вне каталога исходников.

```bat
"C:\UE\Engine\Build\BatchFiles\RunUAT.bat" BuildPlugin -Plugin="D:\Project\Plugins\UAssetImporter\UAssetImporter.uplugin" -Package="D:\Packages\UAssetImporter" -TargetPlatforms=Win64
```

Используйте установку движка, для которой собираете плагин. `-Plugin` указывает путь к дескриптору плагина, `-Package` задаёт папку результата, а `-TargetPlatforms` выбирает целевую платформу.

### Использование собранного плагина

Скопируйте выходную папку с `UAssetImporter.uplugin` в `YourProject/Plugins/UAssetImporter/` для одного проекта или в `Engine/Plugins/Marketplace/UAssetImporter/` для проектов на этой установке движка. Включите плагин в **Edit → Plugins**. При смене версии движка проверьте совместимость API и пересоберите плагин.
