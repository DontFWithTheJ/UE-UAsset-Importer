# UAsset Importer

## Short description

Import external Unreal Engine .uasset packages into your project and choose which dependencies to bring with them.

Импортируйте внешние пакеты Unreal Engine в формате .uasset в свой проект и выбирайте, какие зависимости переносить вместе с ними.

## Fab description

Import external Unreal Engine .uasset packages into your project and choose which dependencies to bring with them. Open one or more assets in the Content Browser import dialog. Review their package paths and references, choose a destination for the assets and their dependencies, then import the selection. Keeping the source project's Content folder structure makes referenced packages easier to locate. Select which references to copy, keep original package paths or choose a destination, and enable rollback when replacing existing assets. Requires readable Unreal Engine packages and their source dependencies.

Импортируйте внешние пакеты Unreal Engine в формате .uasset в свой проект и выбирайте, какие зависимости переносить вместе с ними. Откройте один или несколько ассетов через Content Browser. Проверьте пути пакетов и ссылки, выберите папки для ассетов и зависимостей, затем запустите импорт. Если сохранить структуру исходной папки Content, плагину будет проще найти связанные пакеты. Отметьте нужные зависимости, сохраните исходные пути или укажите целевую папку. При замене ассетов можно включить откат. Для переноса нужны читаемые пакеты Unreal Engine и исходные файлы их зависимостей.
